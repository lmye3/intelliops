四个 Agent

Commander 指挥官

  • 聚合告警、判定严重度、建任务计划
边界：不诊断、不执行

Detective 诊断侦探

  • 调 Skill 取证据，输出候选根因+置信度+证据引用
边界：无执行权（L0）

Ranger 安全执行官

  • 匹配 Runbook、查风险、发起审批、触发沙箱执行
边界：L3 必须人批

Sage 复盘智者

  • 汇总全程、检查证据、写复盘和经验
边界：不改审计记录

每个 Skill 是独立目录：manifest.json + input.schema.json + output.schema.json + index.js + SKILL.md，输入经 JSON Schema draft 2020-12 严格校验。
