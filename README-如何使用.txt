灵瞳智维 IntelliOps v16.0 使用说明

一、启动
双击“灵瞳智维IntelliOps.exe”。程序会在独立窗口中打开，后端隐藏运行，不需要手动打开终端或浏览器。

二、配置AI
点击左侧“AI配置”。第一次填写 Endpoint、API Key 和模型名并保存。以后重新打开时，页面不会显示明文Key，但会显示“已安全保存并成功加载”；输入框留空不会删除原Key。

三、添加真实监控
进入“监控目标”，可添加HTTP地址、TCP端口、Windows进程、应用程序或Windows服务。普通应用只监测和诊断，不会擅自重启。Windows服务自动启动必须经过L3人工审批。

四、五分钟比赛演示
进入“五分钟演示中心”，选择以下任一场景：网关高延迟、支付错误配置、支付服务退出、库存受管应用退出。系统会使用真实本地HTTP请求采集修复前、故障中和修复后指标。
建议比赛现场选择“库存应用退出”：流程会经过Commander、Detective、官方AgentTeams协作、Ranger风险检查，并停在L3人工审批。点击“批准并继续”后，库存应用会以新的真实进程PID重启，再由原HTTP探测器复验。

五、三类安全恢复
恢复基线配置：只修改项目自带数字孪生配置。
重启受管服务：只重启项目自带网关或支付服务监听器。
重启受管应用：只重启项目自带库存应用进程，并且必须L3人工审批。
三类动作均禁止任意Shell和LLM文本执行。

六、查看闭环证据
异常出现后进入“异常事件”和“协作Trace”。Trace页面会显示Agent顺序、Skill结构校验、工具调用、AI调用回执、Token用量（服务商返回时）和证据链状态。

七、比赛评测
进入“量化评测”，运行50条受控测试。结果包含35条留出/盲测案例，并明确列出系统尚不能识别的故障，不代表生产环境准确率。

八、官方AgentTeams协作
本机已部署官方AgentTeams v1.2.2容器时，APP启动会创建一次临时本地会话。进入“官方AgentTeams”，选择事件后可异步派发给Commander；结果返回后会进入Trace。临时凭据只存在于本次进程内，退出时注销。

九、电脑系统安全恢复
普通应用、HTTP和TCP目标默认只监控、诊断并给出建议。只有白名单中的Windows服务可在L3人工审批后启动；不会执行LLM生成的命令，也不允许任意Shell。

十、退出
使用窗口关闭按钮退出。程序会同时停止本地后端并释放8766端口。用户数据和加密Key保存在当前Windows用户的本地应用数据目录中。

说明：未连接官方AgentTeams时APP会明确显示本地可验证模式，不会冒充官方运行实例。AI效果页只统计本机真实成功调用产生的配对样本；没有样本时不会宣称提升。
